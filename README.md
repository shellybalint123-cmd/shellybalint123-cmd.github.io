# SB MEDIA - שלי באלינט

אתר תיק עבודות סטטי (HTML / CSS / JS ללא build), מתפרסם ישירות מ-GitHub Pages.

## מבנה האתר
סדר המקטעים ב-`index.html`:

1. **Hero** (`#top`) - כותרת, כפתורים ואזור Showreel
2. **עבודות נבחרות** (`#work`) - פרויקטים לפי תחום (לשונית "הכל" ראשונה)
3. **תוצאות** (`#results`) - שני Case Studies + "נתוני ביצועים נוספים" (נפתח בלחיצה)
4. **שירותים** (`#services`)
5. **אודות** (`#about`)
6. **המלצות** (`#testimonials`)
7. **צור קשר** (`#contact`)

פלטת הצבעים והפונטים (שפה עיצובית Editorial): שמנת `#F5F2E9`, כחול מותג `#080E3D`, פחם `#202020`, אפור חם `#D9D7D0` ולבן. כולם מוגדרים בראש `styles.css`.
פונטים: Syne Bold לכותרות גדולות באנגלית, Heebo לתוכן בעברית ו-DM Sans לטקסטים קטנים באנגלית. הקבצים מאוחסנים באתר עצמו ב-`assets/fonts/`, בלי תלות ב-Google Fonts.

## איך מוסיפים סרטון לפרויקט
1. מעלים את הסרטון ל-`public/videos/` (MP4, H.264, מומלץ 720p אנכי). לסרטונים כבדים (מעל ~15MB) כדאי ליצור גם גרסה קלה ב-`public/videos/light/` ולהפנות אליה ב-`data-video`. הקובץ המקורי נשאר ב-`public/videos/`.
2. שומרים תמונת תצוגה (480px רוחב) ב-`public/videos/thumbs/` באותו שם (למשל `my-video.jpg`).
3. ב-`index.html`, בתוך הפרויקט המתאים (`<ul class="vgrid">`), מעתיקים בלוק `<li class="vitem" data-item>` קיים ומחליפים את שם הקובץ ב-`data-video`, `data-thumb` ובתמונה.
4. ארבעת הסרטונים הראשונים בכל פרויקט מוצגים מיד. סרטונים נוספים צריכים את `data-extra` ב-`<li>` והם נחשפים בכפתור "הצגת כל ה...".

הסרטונים לא נטענים ולא מתנגנים בגלילה. לחיצה על תמונה פותחת נגן מוגדל שמתחיל מיד עם סאונד (פעם אחת, בלי לופ). בסיום מופיע כפתור הפעלה חוזרת. בנגן: סגירה, השתקה, מסך מלא, מעבר בין סרטונים בחצים/החלקה/מקלדת.
אם הדפדפן חוסם הפעלה עם סאונד מוצג כפתור Play ברור. אם גרסה קלה (`light/`) לא נטענת, הנגן עובר אוטומטית לקובץ המקורי, ואם גם הוא נכשל מוצגת הודעה עם כפתור ניסיון חוזר.

## Showreel
באזור הפתיחה יש מקום מוכן ל-Showreel. כדי להפעיל אותו, מעלים סרטון (למשל `public/videos/showreel.mp4`) ובקובץ `index.html` ממלאים את `data-src`:

```html
<div class="showreel" id="showreel" data-src="public/videos/showreel.mp4" ...>
```

עד אז מוצג פס תמונות מהעבודות עם התווית "בקרוב".

## תצוגת קישור בוואטסאפ
תג ה-Open Graph (כותרת, תיאור ותמונה) נמצא בראש `index.html`, והתמונה היא `assets/og-image.jpg` (1200x630, רקע `#080E3D`, הלוגו, SB MEDIA ו-Social Media & Creative Studio).
וואטסאפ שומרת תצוגה מקדימה של כל קישור במטמון. כדי לראות שינוי בתמונה או בטקסט, שולחים את הקישור עם סימן שאלה בסוף, למשל `https://shellybalint123-cmd.github.io/?v=2`.
הכתובת המלאה בתגים (`og:url`, `og:image`) מוגדרת לפי כתובת האתר הנוכחית. אם הכתובת משתנה, יש לעדכן אותה.
